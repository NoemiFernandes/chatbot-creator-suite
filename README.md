# Chatbot Creator Suite

## Sobre o projeto
O **Chatbot Creator Suite** é um protótipo web para criação e gerenciamento de chatbots, desenvolvido como projeto prático de estudo.

A proposta do projeto é explorar a construção de uma aplicação com foco em organização de fluxos, cadastro e gerenciamento de bots, além de integração com serviços externos por webhook.

## Objetivo
Este projeto foi desenvolvido com o objetivo de praticar:

- organização de um projeto com proposta de produto
- estruturação de uma aplicação web
- integração entre frontend, banco de dados e automações externas
- documentação de projeto no GitHub

## Funcionalidades
Entre os pontos trabalhados no projeto, estão:

- criação e gerenciamento de chatbots
- integração com Supabase
- uso de webhook para comunicação com automações externas
- prototipação e publicação de aplicação web

## Tecnologias utilizadas
Neste projeto foram utilizadas ferramentas e serviços como:

- Lovable
- Supabase
- Webhooks
- Git e GitHub
